# 监控、告警与诊断 Agent

## 观测信号

- 指标：请求成功率、延迟、吞吐、Pod 重启、资源使用、PVC 状态。
- 日志：应用错误、数据库连接、控制器和部署事件。
- 事件：Pending、FailedMount、BackOff、探针失败、调度失败。
- 变更：Git commit、GitOps 同步、镜像或配置变更。

## 告警原则

告警必须说明对象、时间窗口、阈值、影响和建议的第一步检查。避免只根据单个 CPU 指标判断根因。

## Agent 约束

诊断 Agent 的输出至少包含：

1. 观测到的现象；
2. 证据及时间范围；
3. 按置信度排序的假设；
4. 安全的验证动作；
5. 需要人工批准的破坏性动作。

评测集应包含 PVC Pending、镜像拉取失败、探针失败、依赖不可用、资源不足和错误发布等可复现样例。
