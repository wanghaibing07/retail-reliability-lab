# 事件记录

每个可复现故障使用一个独立 Markdown 文件，例如：
`2026-09-11-pvc-pending.md`。

## 模板

```markdown
# 事件：<简短标题>

- 发生时间：
- 恢复时间：
- 环境/命名空间：
- 影响范围：
- 严重度：

## 现象

## 时间线

## 证据

- 指标：
- 日志：
- Kubernetes 事件：
- 最近变更：

## 假设与排除

## 根因

## 恢复动作

## 为什么恢复动作有效

## 预防与自动化改进

## 可复现步骤
```

复盘重点不是描述“执行了重启”，而是说明触发信号、证据链、根因、恢复验证和如何减少下一次人工判断。
