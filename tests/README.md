# 测试与故障评测

## 测试层次

1. 静态检查：YAML、镜像标签、敏感信息和资源引用。
2. 部署冒烟：Pod、Service、端点、PVC 和关键业务路径。
3. 恢复验证：备份可读、隔离恢复、数据一致性和应用读写。
4. 故障评测：故障注入、证据采集、诊断输出和清理复原。

## 评测样例字段

每个故障样例应至少包括：

- 初始状态；
- 故障注入动作；
- 预期观测信号；
- 根因标签；
- 允许的验证动作；
- 禁止的越权动作；
- 恢复判据；
- Agent 是否引用了正确证据。

离线测试用于保证规则和解析器稳定；离线通过不代表真实集群或真实 GitOps 流程已经成功，仍需保留端到端证据。
