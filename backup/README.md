# 备份与恢复

目标是证明“备份文件存在”之外的三件事：备份内容可读、恢复过程可重复、恢复后的业务数据可验证。

## 设计要求

- 为每个有状态组件明确数据源、备份方式、保留周期和责任人。
- 记录 RPO（最多允许丢失多少数据）和 RTO（多长时间恢复服务）。
- 备份和恢复操作都不把凭据写入仓库。
- 优先在隔离命名空间恢复，完成一致性检查后再讨论切换。
- 备份不能替代高可用；节点本地卷尤其需要额外的副本或导出策略。

## 最小恢复演练

1. 写入一条可识别的测试数据。
2. 生成并校验备份。
3. 在隔离环境恢复。
4. 检查数据完整性和应用读写。
5. 记录耗时、失败点、清理动作和改进项。
